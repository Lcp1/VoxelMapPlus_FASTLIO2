## 0. 符号速查

| 符号 | 含义 |
|---|---|
| p_l, p_w | 点在 LiDAR 本体坐标系 / 世界坐标系下的坐标 |
| R_wl, t_wl | LiDAR 到世界的旋转和平移 |
| n, q | 平面单位法向量、平面上一点（通常取质心） |
| Σ_lidar | 单点在 LiDAR 系下的量测协方差（3×3） |
| Σ_w | 单点在世界系下的协方差（3×3，含位姿不确定度） |
| Σ_plane | 平面参数 (n, q) 的 6×6 协方差（代码 plane_cov） |
| Σ_nq | 法向-质心交叉块（3×3），是 Σ_plane 的一部分 |
| C_i | 第 i 个点的 3×3 协方差（代码 pv.cov） |
| P | IESKF 的误差状态协方差（23×23） |
| J | 雅可比矩阵 |
| λ_0 <= λ_1 <= λ_2 | 点云散布矩阵的特征值（Eigen 升序，λ_0 最小） |
| u_0, u_1, u_2 | 对应的特征向量；u_0 就是法向 n |
| [a]× | 向量 a 的反对称矩阵，[a]× b = a × b |
| ^T | 转置 |
| ^-1 | 逆 |
| ~=, =>, <=, >=, != | 约等于、推出、小于等于、大于等于、不等于 |

## 1. 点到面残差是怎么算的？

### 1.1 残差本身

平面用单位法向 n 和平面上一点 q 表示：

```
n^T (x - q) = 0
```

世界系点 p_w 到平面的有符号距离就是残差：

```
r = n^T (p_w - q)
```

- r = 0：点在平面上；
- r > 0：点在法向正侧；
- r < 0：点在法向负侧。

代码对应：

```cpp
p2m = point_world - plane_mean;
residual = plane_norm * p2m;
```

### 1.2 对平面参数的雅可比

r 同时依赖平面参数 n、q 和点 p_w：

```
∂r/∂n = (p_w - q)^T          （1×3）
∂r/∂q = -n^T                 （1×3）
```

拼成 1×6：

```
J_nq = [ (p_w - q)^T , -n^T ]
```

它的作用：把平面参数的 6 维不确定度映射到残差这个标量上。

代码对应：

```cpp
J_nq[0:3] = p2m^T;
J_nq[3:6] = -plane_norm^T;
```

### 1.3 残差方差

平面参数本身有协方差 Σ_plane（6×6），当前点有协方差 Σ_w（3×3）。一阶传播：

```
σ_r^2 = J_nq Σ_plane J_nq^T + n^T Σ_w n
```

两项分别是：

1. **地图平面不确定度**：J_nq Σ_plane J_nq^T；
2. **当前点不确定度在法向上的投影**：n^T Σ_w n。

因为残差对点的偏导是：

```
∂r/∂p_w = n^T
```

所以点的误差椭球投影到法向上，正好是 n^T Σ_w n。

代码里的 `sigma_l` 就是这个 σ_r^2：

```cpp
sigma_l  = J_nq * plane_cov * J_nq^T;
sigma_l += plane_norm^T * cov_world * plane_norm;
```

> 注意：`sigma_l` 是**方差**，不是标准差；下面要开根号。

### 1.4 3σ 检验

在零假设“点确实落在该平面上”下：

```
r ~ N(0, σ_r^2)

=> r / σ_r ~ N(0, 1)
```

所以：

```
|r| < 3 σ_r
```

约 99.7% 置信。超过就认为这个点到面匹配不可信，标记为外点：

- 体素量化导致点落到错误平面；
- 动态物体；
- 非平面结构（树叶、草丛）；
- 地图或位姿误差过大。

代码：

```cpp
if (|residual| < 3 * sqrt(sigma_l))
    is_valid = true;
```

### 1.5 为什么用自适应门限

σ_r 会随场景自动变化：

- 远处点：方向噪声 × 距离、位姿杠杆臂变大 => σ_r 大 => 门限自动放宽；
- 近处点：σ_r 小 => 门限收紧；
- 点多的平面：Σ_plane 小 => 门限收紧；
- 杂乱区域的“平面”：Σ_plane 大 => 门限放宽。

固定一个 0.1 m 之类的阈值，无法同时适应近/远、好/坏平面。

### 1.6 一句话总结

> 残差是“点离平面有多远”，σ_r 是“这个距离本来应该有多大的抖动”，3σ 就是问“它远得是否合理”。

## 2. plane_cov 和 cov_world 都是给 IESKF 的吗？

不完全是。它们都是**观测模型里的协方差**，但 IESKF 并不会直接拿到这两个矩阵；它最终只拿到由它们算出的**标量信息权重** 1/r_cov，以及 H_obs、b_obs。IESKF 自己的状态协方差是 P。

### 2.1 三个协方差的区别

| 量 | 维度 | 来源 | 用在哪里 |
|---|---|---|---|
| plane_cov | 6×6 | 地图平面 (n, q) 的拟合协方差 | ① 3σ 门限；② IESKF 观测权重 |
| cov_world | 3×3 | 当前点：雷达量测噪声 + 当前位姿不确定度 | ① 3σ 门限；② 地图更新时的 pv.cov |
| cov_lidar | 3×3 | calcBodyCov()：测距/测角噪声（本体系） | IESKF 观测权重（旋转到世界后取法向投影） |
| P | 23×23 | IESKF 状态先验/后验协方差 | 先验项；也是 cov_world 的组成部分 |

### 2.2 数据流

```
LiDAR 点 p_l
   │
   ▼
calcBodyCov() ──► cov_lidar (3×3)
   │
   ▼
cov_world = R cov_lidar R^T
          + [p_l]× P_RR [p_l]×^T
          + P_tt                 (3×3，含当前位姿不确定度)
   │
   ├──► 建图：pv.cov = cov_world ──► updatePlane() ──► plane_cov (6×6)
   │
   ▼
buildResidual()
   residual = n^T(p_w - q)
   sigma_l  = J_nq plane_cov J_nq^T + n^T cov_world n
   3σ 门限 ──► is_valid
   │
   ▼
sharedUpdateFunc()
   r_cov  = J_nq plane_cov J_nq^T + n^T (R cov_lidar R^T) n
   r_info = 1 / r_cov
   H_obs += J^T r_info J
   b_obs += J^T r_info residual
   │
   ▼
IESKF
   H = J_prior^T P^-1 J_prior + H_obs
   b = J_prior^T P^-1 δ + b_obs
   δx = -H^-1 b
```

### 2.3 为什么 3σ 用 cov_world，权重却用 cov_lidar

**3σ 门限**问的是：

> “当前这个世界系点与地图平面是否统计一致？”

当前点的世界坐标 = 位姿 × 雷达点。位姿本身有误差，所以点的世界坐标不确定度里必须包含当前位姿不确定度 P。因此用 cov_world 是对的。

**IESKF 权重**问的是：

> “这个观测应该以多大权重进入滤波器？”

滤波器的状态就是位姿，位姿不确定度已经通过先验项 P^-1 和状态雅可比 H 进入了正规方程。如果再在观测噪声 R 里放一份含 P 的 cov_world，同一份位姿不确定度就被算了两次，滤波器会过度不信任观测。

所以权重里只用：

```
r_cov = J_nq Σ_plane J_nq^T + n^T (R_wl Σ_lidar R_wl^T) n
```

即 **地图平面不确定度 + 雷达局部量测噪声**，不含当前位姿不确定度。

这正对应 VoxelMap 论文里：

- 关联检验用世界系点协方差 Σ_Wp（含位姿误差）；
- 状态估计观测噪声用本体系点协方差 Σ_Lp（不含位姿误差，避免重复计数）。

### 2.4 一句话总结

> plane_cov 是“地图平面的不确定度”，cov_world 是“当前点的世界系不确定度（含量测噪声和当前位姿误差）”。
>
> **3σ 门限两者都用；IESKF 权重只用 plane_cov + cov_lidar**，因为当前位姿不确定度已经由先验 P 处理，再用 cov_world 会重复计数。

## 3. 平面协方差是怎么推导的？

### 3.1 样本均值与散布矩阵

体素内有 N 个点 p_1 … p_N，定义质心：

```
q = (1/N) ∑_i p_i
```

样本散布矩阵：

```
A = (1/N) ∑_i (p_i - q)(p_i - q)^T
```

代码里用二阶矩在线累加：

```
ppt = ∑_i p_i p_i^T

A = ppt / N - q q^T
```

### 3.2 PCA 与平面判定

对 A 做对称特征分解：

```
A = U Λ U^T

U = [u_0 u_1 u_2]
Λ = diag(λ_0, λ_1, λ_2)

λ_0 <= λ_1 <= λ_2        （Eigen 升序）
```

- 最小特征值 λ_0 对应的特征向量就是法向：n = u_0；
- u_1、u_2 张成平面内的方向；
- 平面判定：λ_0 < τ。λ_0 表示点云在法向上的展布，太大说明这个体素里的点不共面。

### 3.3 点扰动对散布矩阵的影响

只扰动第 i 个点 p_i，记：

```
v_i = p_i - q
```

质心也会变：δq = δp_i / N。代入 A 的定义，并利用 ∑_j v_j = 0，可以推出：

```
δA = (1/N) ( δp_i v_i^T + v_i δp_i^T )
```

注意没有额外的 1/N^2 项，因为质心随点变化的部分恰好抵消。

### 3.4 特征向量的一阶扰动

设特征值互异。对

```
(A + δA)(u_0 + δu_0) = (λ_0 + δλ_0)(u_0 + δu_0)
```

展开，保留一阶项：

```
A δu_0 + δA u_0 = λ_0 δu_0 + δλ_0 u_0
```

两边左乘 u_m^T（m != 0），利用 u_m^T A = λ_m u_m^T、u_m^T u_0 = 0：

```
(λ_m - λ_0) u_m^T δu_0 + u_m^T δA n = 0
```

即：

```
u_m^T δu_0 = (u_m^T δA n) / (λ_0 - λ_m)
```

又因为 ||u_0 + δu_0|| = 1，一阶意义下 u_0^T δu_0 = 0，所以：

```
δn = ∑_{m=1,2} [ (u_m^T δA n) / (λ_0 - λ_m) ] u_m
```

### 3.5 代入 δA，得到法向雅可比

```
u_m^T δA n = (1/N) [ (u_m^T δp_i)(v_i^T n) + (v_i^T u_m)(n^T δp_i) ]
```

代回 δn：

```
∂n/∂p_i = ∑_{m=1,2} 1/[N(λ_0 - λ_m)]
          [ (v_i^T n) u_m u_m^T + (v_i^T u_m) u_m n^T ]
```

若点严格落在平面上，v_i^T n ~= 0，第一项（对称项）可以忽略，退化成常见的：

```
∂n/∂p_i ~= ∑_{m=1,2} [ (v_i^T u_m) / (N(λ_0 - λ_m)) ] u_m n^T
```

### 3.6 质心雅可比

质心是均值：

```
q = (1/N) ∑_j p_j

=> ∂q/∂p_i = (1/N) I_3
```

### 3.7 拼成 6×6 协方差

把法向和质心的雅可比拼起来：

```
J_i = [ ∂n/∂p_i ]   （6×3）
      [ ∂q/∂p_i ]
```

假设不同点的噪声相互独立（近似），则：

```
Σ_plane = ∑_i J_i C_i J_i^T
```

展开成四个块：

```
Σ_nn = ∑_i J_{n,i} C_i J_{n,i}^T
Σ_nq = ∑_i J_{n,i} C_i (1/N) I
Σ_qn = Σ_nq^T
Σ_qq = (1/N^2) ∑_i C_i
```

代码里：

```cpp
plane_->cov += J * pv.cov * J.transpose();
```

就是在累加 ∑_i J_i C_i J_i^T，**完整保留法向-质心的交叉块**。

### 3.8 代码里的 F_m 与 U F

代码构造的是法向雅可比的“行形式”。令：

```
F_m = 1/[N(λ_0 - λ_m)] v_i^T (u_m n^T + n u_m^T)

   = 1/[N(λ_0 - λ_m)] [ (v_i^T u_m) n^T + (v_i^T n) u_m^T ]
```

这是一个 1×3 行向量。代码：

```cpp
F_m = (p_i - q)^T / (N (λ_0 - λ_m)) * (u_m n^T + n u_m^T);
F.row(m) = F_m;
```

然后把 F 的第 1、2 行填好（第 0 行保持零），再算：

```
U F = ∑_{m=1,2} u_m F_m
    = ∑_{m=1,2} 1/[N(λ_0 - λ_m)]
      [ (v_i^T u_m) u_m n^T + (v_i^T n) u_m u_m^T ]
```

正好等于 3.5 节的 ∂n/∂p_i。所以：

```cpp
J.block<3,3>(0,0) = evecs * F;   // ∂n/∂p_i
J.block<3,3>(3,0) = J_Q;         // ∂q/∂p_i = I/N
```

### 3.9 几个性质

- Σ_nn 的秩至多 2：因为 δn ⊥ n，法向只有 2 个有效方向；
- Σ_qq 按 1/N^2 下降：点越多，质心越确定；
- Σ_nq != 0：法向和质心都由同一批点估计，噪声会把平面“掰弯”的同时移动质心；
- 整个 6×6 协方差有一个零空间方向 [n; 0]（法向缩放），所以秩至多 5；点到面残差恰好不受这个方向影响。

### 3.10 实现注意

1. **Plane::cov 没有显式初始化**：Eigen 固定尺寸矩阵默认构造不保证清零，`+=` 前应显式 `Zero()`。
2. **updatePlane() 累加前没有清零**：`updatePlane()` 会被多次调用（每 update_point_thresh_ 个点一次），如果 `plane_->cov += ...` 前不 `setZero()`，同一批点会被重复累加。
3. **buildResidual() 没有把平面协方差写入 ResidualData**：目前只写了 `plane_norm` 和 `plane_mean`，没有 `data.plane_cov = voxel_grid->plane_->cov;`，后面的 `sigma_l` 和 IESKF 权重会用未初始化值。
4. **is_valid 的过期问题**：未命中体素时不会调用 `buildResidual()`，`is_valid` 会保留上一次的值，应在每帧/每次迭代开始时置 false。
5. **独立性/一阶假设**：公式假设不同点的噪声独立；实际地图点共享建图位姿误差，存在共同模态，结果会偏乐观。

## 4. HASH_P 是“一个平面含体素最大序号数量”吗？

不是。HASH_P = 116101 只是空间哈希函数里的一个**质数乘子**，和“一个平面包含多少个体素”没有关系。

哈希函数：

```
hash = ( ( (z * P) mod M + y ) * P ) mod M + x

P = 116101
M = 10 000 000 000   （MAX_N）
```

- P 是质数乘子，用来打散 x、y、z 的分布；
- M 是取模上限，主要目的是**防止乘法在 int64 上溢出**。

它**不是**体素数量、不是序号上限、也不是平面容量。

真正的数量限制在这些参数上：

| 参数 | 当前值 | 含义 |
|---|---|---|
| max_point_thresh | 100 | 单个体素最多累积多少个点 |
| update_size_thresh | 10 | 每新增多少个点重算一次平面 |
| map_capacity | 100000 | 整个地图最多多少个活跃体素 |
| group_id | 自增 | 平面合并的分组 ID，与 HASH_P 无关 |

“一个平面包含多少个体素”在代码里没有显式上限；一个 group 可以包含很多体素，只受 map_capacity 和内存限制。

> 哈希冲突不影响正确性：unordered_map 的 key 是完整的 (x, y, z)，冲突时还会用 operator== 逐个比较 key。哈希值相同但 key 不同的两个体素不会被当成同一个。

## 5. MAX_N 是某一维的最大值吗？

不是。MAX_N 是对整个累加值取模的上限，不是“y 轴最大值”或“x 轴最大值”。

把公式展开（忽略中间的取模）：

```
h ~= z * P^2 + y * P + x
```

所以更准确的理解是：

- P 是权重/进位基数，不是“某一维的最大值”；
- z 的权重是 P^2，y 的权重是 P，x 的权重是 1；
- 第一个 P 把 z 的贡献“左移一位”，然后加上 y；
- 第二个 P 把 (zP + y) 再“左移一位”，然后加上 x。

这就像把三维坐标写成一个“以 P 为基数”的数：

```
(z, y, x)  ──►  z*P^2 + y*P + x
```

P 是进制，不是某一维的上限。

MAX_N 的作用是防止中间结果溢出。如果没有取模，zP^2 + yP + x 在坐标稍大时就会超过 int64 的范围（约 9.2×10^18）。取模把中间值压到 10^10 量级，再乘 P 也只有约 1.16×10^15，仍然安全。

数值例子（z=10, y=20, x=30）：

```
zP = 10 × 116101 = 1 161 010
(zP mod M) + y = 1 161 010 + 20 = 1 161 030
((...) × P) mod M = (1 161 030 × 116 101) mod 10^10
h = 上一步结果 + 30
```

没有哪一步在说“y 的最大值是 116101”或“x 的最大值是 116101”。

## 6. 这算不算定义不同轴的格子序号、避免重复？

**算一种“带位置权重的哈希编码”，但不是严格唯一的序号。**

你的直觉方向是对的：

- 把三个轴的格子索引 x、y、z 组合成一个标量；
- 用 P^2、P、1 这样的位置权重，让不同轴的贡献落在不同的“数位”上；
- 这样 (x, y, z) = (1, 2, 3) 和 (3, 2, 1) 一般不会得到同一个值，减少了不同维度/不同格子“撞号”的概率。

在**没有取模、坐标范围有限**的理想情况下，它确实是一个唯一的混合进制编码：

```
h = z*P^2 + y*P + x
```

只要 0 <= x, y < P，就可以像 base-P 一样唯一还原 (x, y, z)。

但代码里有两个关键区别：

1. **有取模，会回绕**：MAX_N = 10^10 会在中途取模，大的坐标会绕回来，不同的 (x, y, z) 可能得到相同的哈希值。
2. **坐标没有限制在 [0, P)**：x、y、z 是 int64，可以远大于 P，也可以是负数。一旦某个“数位”超过 P，就会产生进位，导致碰撞。

例如在无模的精确算术下：

```
(z=0, y=P, x=0)  =>  h = P^2
(z=1, y=0, x=0)  =>  h = P^2
```

两者撞在一起。所以这个编码**不是严格唯一**的。

真正的去重靠 unordered_map 的 key 比较：

- 先用 Hasher 算出哈希值，决定放到哪个桶；
- 桶里再用 operator== 逐个比较 (x, y, z)。

所以哈希冲突只影响性能（桶变长），不影响正确性。

**一句话**：它是在用一个带位置权重的哈希函数，把三个轴的格子索引压成一个“桶号”，让不同轴的格子尽量分散到不同的桶里，减少重复；但它不是严格唯一的体素编号，真正的身份仍然是 (x, y, z)。

---

## 7. 限制每个轴的大小、超出就删除，是不是更安全？

要分“安全”指什么。

### 7.1 正确性：不需要

unordered_map 的 key 是完整的 (x, y, z)，哈希冲突时还会比较 key。两个不同体素不会因为哈希值相同而被合并，所以当前设计在正确性上已经安全。

真正危险的是把哈希值直接当 key（例如 unordered_map<int64_t, VoxelGrid>），那样冲突才会导致体素被错误合并。当前代码没有这个问题。

### 7.2 内存：当前已有 capacity + LRU

VoxelMap 有容量上限：

```
map_capacity = 100000
```

超出后按 LRU 淘汰最久未使用的体素。所以“限制总量、超出删除”这个机制已经存在，只是策略是 **LRU（按最近使用）**，而不是 **按坐标轴范围**。

LRU 的好处是：机器人回到旧区域时，那些体素可能还在（最近被重新访问过）；固定轴范围会把边界外的体素无条件删掉，哪怕它刚刚还被用到。

### 7.3 限制轴范围 + 删除的优缺点

**优点**

- 坐标范围固定，可以用完美编码（例如 (z*N + y)*N + x）代替哈希，彻底没有冲突；
- 内存有确定上界，最坏情况可预估；
- 实现简单，调试直观；
- 对“只关心附近环境”的局部建图/避障够用。

**缺点**

- 丢失回访能力：机器人走出范围后，旧区域被删除；再回来时地图已经没了，无法重定位或做回环；
- 边界效应：固定窗口的边界会频繁删除/重建体素，可能导致平面参数抖动；
- 范围难选：太小不够用，太大内存爆炸；LRU 是自适应地保留“最近用过”的体素，通常比固定窗口更合理；
- 不解决动态场景：删除只是清内存，不代表地图语义正确；
- 密集数组的内存代价：每个轴限制 N，稠密数组是 N^3。N=256 就是 1677 万格；每格还要存平面/指针，内存很容易上百 MB。

### 7.4 结论

- **正确性**：不需要限制轴，当前 unordered_map + key 相等已经安全；
- **内存**：capacity + LRU 已经提供了上界，而且比按轴范围删除更适合回访；
- **性能**：换一个更好的 64 位哈希（如 splitmix64）比限制轴范围更直接；
- **如果你要做的是局部地图/嵌入式受限内存**：限制轴范围 + 删除是合理的工程选择，但要接受“丢失回访能力”的代价；如果还要回环，最好保留一份全局地图或关键帧。

## 附录 A：δA = (1/N)(δp_i v_i^T + v_i δp_i^T) 的推导

设：

```
q = (1/N) ∑_j p_j
v_j = p_j - q
∑_j v_j = 0
```

只扰动 p_i：

```
δq = (1/N) δp_i
δv_i = δp_i - δq = ((N-1)/N) δp_i
δv_j = -δq = -(1/N) δp_i     (j != i)
```

又：

```
A = (1/N) ∑_j (p_j - q)(p_j - q)^T
  = (1/N) ∑_j v_j v_j^T
```

所以：

```
δA = (1/N) ∑_j ( δv_j v_j^T + v_j δv_j^T )

   = (1/N) [
       ((N-1)/N)( δp_i v_i^T + v_i δp_i^T )
       - (1/N) ∑_{j!=i} ( δp_i v_j^T + v_j δp_i^T )
     ]
```

利用 ∑_{j!=i} v_j = -v_i，第二项为：

```
- (1/N)( δp_i (-v_i)^T + (-v_i) δp_i^T )
= (1/N)( δp_i v_i^T + v_i δp_i^T )
```

两项合并：

```
δA = (1/N)[ (N-1)/N + 1/N ]( δp_i v_i^T + v_i δp_i^T )
   = (1/N)( δp_i v_i^T + v_i δp_i^T )
```

证毕。

## 附录 B：特征向量扰动公式

对对称矩阵 A = U Λ U^T，特征值互异。扰动后：

```
(A + δA)(u_0 + δu_0) = (λ_0 + δλ_0)(u_0 + δu_0)
```

一阶项：

```
A δu_0 + δA u_0 = λ_0 δu_0 + δλ_0 u_0
```

左乘 u_m^T（m != 0）：

```
(λ_m - λ_0) u_m^T δu_0 + u_m^T δA u_0 = 0
```

所以：

```
u_m^T δu_0 = (u_m^T δA u_0) / (λ_0 - λ_m)
```

由于 u_0^T δu_0 = 0（单位向量约束）：

```
δn = δu_0
   = ∑_{m=1,2} [ (u_m^T δA n) / (λ_0 - λ_m) ] u_m
```

## 附录 C：为什么 U F 等于法向雅可比

代码里：

```
F_m = 1/[N(λ_0 - λ_m)] v_i^T (u_m n^T + n u_m^T)
```

展开：

```
F_m = 1/[N(λ_0 - λ_m)] [ (v_i^T u_m) n^T + (v_i^T n) u_m^T ]
```

于是：

```
U F = ∑_{m=1,2} u_m F_m

    = ∑_{m=1,2} 1/[N(λ_0 - λ_m)]
      [ (v_i^T u_m) u_m n^T + (v_i^T n) u_m u_m^T ]
```

正好是法向雅可比的两项。F 的第 0 行保持为零，因为循环从 m=1 开始；这对应“法向自身方向不参与”的约束。

## 10. 一句话总结

> **点协方差**：测距/测角噪声给出 Σ_lidar，再叠加当前位姿误差得到 Σ_w。
>
> **平面协方差**：把 (n, q) 看成点的函数，用特征向量扰动求 ∂n/∂p，用均值求 ∂q/∂p，再按 ∑_i J_i C_i J_i^T 传播。
>
> **残差与滤波**：残差 r = n^T(p - q) 的方差由“平面不确定度 + 点不确定度”组成；3σ 用它做关联门限，IESKF 用“平面不确定度 + 局部量测噪声”做信息权重，避免与先验重复计数。
