# 残差与协方差计算说明

> 对应代码：
>
> - `voxel_plus/src/map_builder/voxel_map.h/.cpp`：体素、平面拟合、平面协方差、点到面残差与 3σ 门限
> - `voxel_plus/src/map_builder/lio_builder.cpp`：点云预处理、世界系点协方差、IESKF 观测权重
> - `voxel_plus/src/map_builder/commons.cpp`：`calcBodyCov()`，雷达本体系量测协方差
> - `voxel_plus/src/map_builder/ieskf.h/.cpp`：迭代误差状态卡尔曼滤波
>
> 本文把 **“单点量测协方差 → 世界系点协方差 → 平面拟合协方差 → 点到面残差方差 → IESKF 观测权重”** 这条链完整推一遍，并逐段对应到代码。
>
> 另有一份按“问题”组织的纯文本版本：[VoxelMap理解问答整理.md](VoxelMap理解问答整理.md)。

## 0. 符号与约定

| 符号 | 含义 |
|---|---|
| \(^{\mathrm L}\mathbf p_i\) | 第 \(i\) 个点在 LiDAR 本体坐标系下的坐标 |
| \(^{\mathrm W}\mathbf p_i\) | 同一点在世界坐标系下的坐标 |
| \(\mathbf R_{wl},\ \mathbf t_{wl}\) | LiDAR 到世界的旋转和平移 |
| \(\mathbf n,\ \mathbf q\) | 平面单位法向量、平面上一点（质心） |
| \(\boldsymbol\Sigma_{\text{lidar}}\) | 单点在 LiDAR 系下的量测协方差（`cov_lidar`） |
| \(\boldsymbol\Sigma_w\) | 单点在世界系下的协方差（`cov_world`） |
| \(\boldsymbol\Sigma_{nq}\) | 平面参数 \((\mathbf n,\mathbf q)\) 的 \(6\times6\) 协方差（`plane_cov`） |
| \(\mathbf P\) | IESKF 的 \(23\times23\) 误差状态协方差（`kf_.P()`） |
| \(\lfloor\cdot\rfloor_\times\) | 反对称矩阵，\(\lfloor\mathbf a\rfloor_\times\mathbf b=\mathbf a\times\mathbf b\) |
| \(\lambda_0\le\lambda_1\le\lambda_2\) | 点云散布矩阵的特征值；Eigen 的 `SelfAdjointEigenSolver` 按升序排列 |

> **Eigen 升序提醒**：`evals(0)` 是**最小**特征值，对应法向；`evals(1)`、`evals(2)` 是另外两个方向。论文里常用降序 \(\lambda_1\ge\lambda_2\ge\lambda_3\)，两者只是下标顺序不同。

本文采用右扰动位姿误差：

\[
\mathbf R=\bar{\mathbf R}\exp(\delta\boldsymbol\theta^\wedge),\qquad
\mathbf t=\bar{\mathbf t}+\delta\mathbf t.
\]

## 1. 总体数据流

系统里有两条并行的链：

```
                         ┌──────────────────────────────┐
                         │  地图（建图/更新）            │
                         │                              │
LiDAR 点 ──► calcBodyCov ──► cov_lidar ──► cov_world ──► updatePlane
   p_l                        3×3            3×3             │
                                                             ▼
                                                    平面 (n,q,Σ_nq)
                                                             │
                         ┌───────────────────────────────────┘
                         ▼
                    buildResidual
                    residual, sigma_l, is_valid
                         │
                         ▼
                    sharedUpdateFunc
                    r_cov, r_info, H_obs, b_obs
                         │
                         ▼
                       IESKF
                    δx, 后验 P
```

两条链共用 `cov_lidar` 和 `cov_world`，但**用法不同**：

- **建图**：`cov_world` 作为地图点的协方差，传入 `updatePlane()`，传播成平面协方差 `Σ_nq`。
- **状态估计**：
  - 3σ 门限用 `plane_cov` + `cov_world`（含当前位姿不确定度）；
  - IESKF 观测权重用 `plane_cov` + `cov_lidar`（不含当前位姿不确定度，避免与先验 \(\mathbf P\) 重复计数）。

## 2. 单点量测协方差：`calcBodyCov()`

### 2.1 推导

LiDAR 的原始测量是“距离 + 方向”：

\[
^{\mathrm L}\mathbf p_i=d_i\,\boldsymbol\omega_i,\qquad \|\boldsymbol\omega_i\|=1,
\]

其中 \(d_i\) 是测距，\(\boldsymbol\omega_i\) 是单位视线方向。

测距噪声 \(\delta d_i\) 沿视线方向；方向噪声 \(\delta\boldsymbol\omega_i\) 在 \(\boldsymbol\omega_i\) 处的切平面内。取切平面正交基 \(\mathbf N=[\mathbf N_1,\mathbf N_2]\in\mathbb R^{3\times2}\)，满足

\[
\mathbf N^T\mathbf N=\mathbf I_2,\qquad \mathbf N^T\boldsymbol\omega_i=\mathbf 0.
\]

把二维方向噪声嵌入三维：

\[
\delta\boldsymbol\omega_i=\mathbf N\,\delta\boldsymbol\omega_{t,i}.
\]

对 \(^{\mathrm L}\mathbf p_i=d_i\boldsymbol\omega_i\) 做一阶展开：

\[
\delta\,^{\mathrm L}\mathbf p_i
=\boldsymbol\omega_i\,\delta d_i+d_i\,\delta\boldsymbol\omega_i
=\underbrace{\begin{bmatrix}\boldsymbol\omega_i & d_i\mathbf N\end{bmatrix}}_{\mathbf A_i}
\begin{bmatrix}\delta d_i\\ \delta\boldsymbol\omega_{t,i}\end{bmatrix}.
\]

因此

\[
\boxed{
\boldsymbol\Sigma_{\text{lidar},i}
=\mathbf A_i
\begin{bmatrix}\sigma_{d_i}^2&\mathbf 0\\
\mathbf 0&\boldsymbol\Sigma_{\omega_i}\end{bmatrix}
\mathbf A_i^T
}
\tag{2.1}
\]

### 2.2 代码对应

`commons.cpp` 的 `calcBodyCov()`：

```cpp
double range_var = range_inc * range_inc;                 // 测距方差
Eigen::Matrix2d direction_var;
direction_var << pow(sin(DEG2RAD(degree_inc)), 2), 0,
                 0, pow(sin(DEG2RAD(degree_inc)), 2);       // 两个切向的方差

Eigen::Vector3d direction(pb);
direction.normalize();                                     // ω
Eigen::Matrix3d direction_hat;                             // hat(ω)
...
Eigen::Matrix<double, 3, 2> N;                             // 切平面正交基
...
Eigen::Matrix<double, 3, 2> A = range * direction_hat * N; // d * hat(ω) * N
cov = direction * range_var * direction.transpose() +
      A * direction_var * A.transpose();
```

这与式 (2.1) 是同一个东西，只是代码把切平面基写成

\[
\mathbf B=\lfloor\boldsymbol\omega\rfloor_\times\mathbf N
\]

（论文里常写成 \(-\lfloor\boldsymbol\omega\rfloor_\times\mathbf N\)，两者差一个符号/ \(90^\circ\) 旋转）。因为 \(\pm\lfloor\boldsymbol\omega\rfloor_\times\mathbf N\) 都是切平面的一组正交基，所以和 \(d_i\mathbf N\) 等价；只要 \(\boldsymbol\Sigma_{\omega}\) 与所用基一致即可。

参数：

- `ranging_cov = 0.04`（单位 m，代码里平方成方差）；
- `angle_cov = 0.1`（单位度，代码里转弧度后取 \(\sin^2\)）。

> 注意：`calcBodyCov()` 拿到的是 **LiDAR 本体系**下的协方差，不含位姿不确定度。位姿不确定度在下一步才叠加。

## 3. 世界系点协方差：`cov_world`

### 3.1 推导

点投影到世界系：

\[
^{\mathrm W}\mathbf p_i=\mathbf R_{wl}\,^{\mathrm L}\mathbf p_i+\mathbf t_{wl}.
\]

采用右扰动 \(\mathbf R_{wl}=\bar{\mathbf R}\exp(\delta\boldsymbol\theta^\wedge)\)、\(\mathbf t_{wl}=\bar{\mathbf t}+\delta\mathbf t\)：

\[
\begin{aligned}
^{\mathrm W}\mathbf p_i
&\approx \bar{\mathbf R}\big(\mathbf I+\lfloor\delta\boldsymbol\theta\rfloor_\times\big)\,^{\mathrm L}\mathbf p_i+\bar{\mathbf t}+\delta\mathbf t\\
&=\bar{\mathbf R}\,^{\mathrm L}\mathbf p_i+\bar{\mathbf t}
-\bar{\mathbf R}\lfloor^{\mathrm L}\mathbf p_i\rfloor_\times\delta\boldsymbol\theta+\delta\mathbf t.
\end{aligned}
\]

所以

\[
\delta\,^{\mathrm W}\mathbf p_i
=\bar{\mathbf R}\,\delta\,^{\mathrm L}\mathbf p_i
-\bar{\mathbf R}\lfloor^{\mathrm L}\mathbf p_i\rfloor_\times\delta\boldsymbol\theta
+\delta\mathbf t.
\]

假设量测噪声、旋转误差、平移误差相互独立：

\[
\boxed{
\boldsymbol\Sigma_w
=\mathbf R\boldsymbol\Sigma_{\text{lidar}}\mathbf R^T
+\mathbf R\lfloor^{\mathrm L}\mathbf p_i\rfloor_\times
\boldsymbol\Sigma_{\theta\theta}
\lfloor^{\mathrm L}\mathbf p_i\rfloor_\times^T\mathbf R^T
+\boldsymbol\Sigma_{tt}
}
\tag{3.1}
\]

三项分别是：

1. 雷达量测噪声旋转到世界系；
2. 姿态误差经过力臂 \(\lfloor^{\mathrm L}\mathbf p_i\rfloor_\times\) 放大；
3. 位置误差。

### 3.2 代码对应

`lio_builder.cpp` 的 `sharedUpdateFunc()`：

```cpp
Eigen::Matrix3d point_crossmat = Sophus::SO3d::hat(point_lidar);
data.cov_world = r_wl * data.cov_lidar * r_wl.transpose()
               + point_crossmat * kf_.P().block<3,3>(R_ID, R_ID) * point_crossmat.transpose()
               + kf_.P().block<3,3>(P_ID, P_ID);
```

建图分支（`process()` 里 `kf_.update()` 之后）用的是**后验** `kf_.P()`：

```cpp
pv.cov = r_wl * cov_lidar * r_wl.transpose()
       + point_crossmat * kf_.P().block<3,3>(R_ID, R_ID) * point_crossmat.transpose()
       + kf_.P().block<3,3>(P_ID, P_ID);
```

> **实现提醒**：代码里的力臂用的是 `hat(point_lidar)`，严格来说应为
> \[
> \lfloor \mathbf R_{IL}\,^{\mathrm L}\mathbf p_i+\mathbf t_{IL}\rfloor_\times,
> \]
> 因为外参也会把点移动到 IMU/世界原点附近。外参接近单位阵/零向量时差异很小；代码注释里也标了这个近似。若要严格一致，应改成 `hat(state.rot_ext * point_lidar + state.pos_ext)`（`sharedUpdateFunc` 里组装状态雅可比时用的就是精确形式）。

## 4. 平面拟合与平面协方差：`updatePlane()`

这一节对应选中的代码：

```cpp
void VoxelGrid::updatePlane()
{
    ...
    Eigen::Matrix3d cov = plane_->ppt / plane_->n - plane_->mean * plane_->mean.transpose();

    Eigen::SelfAdjointEigenSolver<Eigen::Matrix3d> es(cov);
    Eigen::Matrix3d evecs = es.eigenvectors();
    Eigen::Vector3d evals = es.eigenvalues();

    if (evals(0) > plane_thresh_) { is_plane_ = false; return; }
    is_plane_ = true;

    Eigen::Matrix3d J_Q = Eigen::Matrix3d::Identity() / plane_->n;
    Eigen::Vector3d plane_norm = evecs.col(0);
    for (PointWithCov &pv : temp_points_)
    {
        Eigen::Matrix<double, 6, 3> J;
        Eigen::Matrix3d F = Eigen::Matrix3d::Zero();
        for (int m = 1; m < 3; m++)
        {
            Eigen::Matrix<double, 1, 3> F_m =
                (pv.point - plane_->mean).transpose() /
                (plane_->n * (evals(0) - evals(m))) *
                (evecs.col(m) * plane_norm.transpose() +
                 plane_norm * evecs.col(m).transpose());
            F.row(m) = F_m;
        }
        J.block<3,3>(0,0) = evecs * F;
        J.block<3,3>(3,0) = J_Q;
        plane_->cov += J * pv.cov * J.transpose();
    }
}
```

### 4.1 在线统计量与样本协方差

体素内维护三个量：

\[
\mathbf q=\frac1N\sum_{i=1}^N\mathbf p_i,\qquad
\mathbf{ppt}=\sum_{i=1}^N\mathbf p_i\mathbf p_i^T,\qquad
N=\text{点数}.
\]

代码里 `addToPlane()` 用增量均值更新 `mean`，同时累加 `ppt`。于是样本协方差（散布矩阵）可以直接写成

\[
\mathbf A
=\frac{\mathbf{ppt}}{N}-\mathbf q\mathbf q^T
=\frac1N\sum_{i=1}^N(\mathbf p_i-\mathbf q)(\mathbf p_i-\mathbf q)^T.
\tag{4.1}
\]

这就是代码里的 `cov`。它是对称半正定矩阵。

> **数值提醒**：世界坐标很大时，\(\mathbf{ppt}/N\) 与 \(\mathbf q\mathbf q^T\) 两个大数相减会损失有效位。工程上建议先把点平移到体素中心/局部原点再累加，或用 Welford 递推。

### 4.2 PCA 与平面判定

对 \(\mathbf A\) 做对称特征分解：

\[
\mathbf A=\mathbf U\boldsymbol\Lambda\mathbf U^T,\qquad
\mathbf U=[\mathbf u_0,\mathbf u_1,\mathbf u_2],\qquad
\lambda_0\le\lambda_1\le\lambda_2.
\]

- 最小特征值 \(\lambda_0\) 对应的特征向量就是法向：
  \[
  \mathbf n=\mathbf u_0.
  \]
- 另两个方向 \(\mathbf u_1,\mathbf u_2\) 张成平面内的方向。
- 平面判定：
  \[
  \lambda_0<\tau,
  \]
  代码里 `tau = plane_thresh_`（当前 0.01）。\(\lambda_0\) 表示点云在法向上的展布；太大说明这个体素里的点不共面。

### 4.3 法向对点的雅可比

我们要算的是：每个点的噪声如何影响法向 \(\mathbf n\)。

#### 4.3.1 点扰动对散布矩阵的影响

只扰动第 \(i\) 个点 \(\mathbf p_i\)，记

\[
\mathbf v_i=\mathbf p_i-\mathbf q.
\]

质心也会变：\(\delta\mathbf q=\delta\mathbf p_i/N\)。代入 \(\mathbf A\) 的定义，并利用 \(\sum_j\mathbf v_j=\mathbf 0\)，可以推出（完整展开见附录 A）：

\[
\boxed{
\delta\mathbf A
=\frac1N\left(\delta\mathbf p_i\,\mathbf v_i^T+\mathbf v_i\,\delta\mathbf p_i^T\right)
}
\tag{4.2}
\]

注意没有额外的 \(1/N^2\) 项，因为质心随点变化的部分恰好抵消。

#### 4.3.2 特征向量的一阶扰动

设特征值互异。对

\[
(\mathbf A+\delta\mathbf A)(\mathbf u_0+\delta\mathbf u_0)
=(\lambda_0+\delta\lambda_0)(\mathbf u_0+\delta\mathbf u_0)
\]

展开，保留一阶项：

\[
\mathbf A\,\delta\mathbf u_0+\delta\mathbf A\,\mathbf u_0
=\lambda_0\,\delta\mathbf u_0+\delta\lambda_0\,\mathbf u_0.
\]

两边左乘 \(\mathbf u_m^T\)（\(m\ne0\)），利用 \(\mathbf u_m^T\mathbf A=\lambda_m\mathbf u_m^T\)、\(\mathbf u_m^T\mathbf u_0=0\)：

\[
(\lambda_m-\lambda_0)\mathbf u_m^T\delta\mathbf u_0
+\mathbf u_m^T\delta\mathbf A\,\mathbf n=0,
\]

即

\[
\mathbf u_m^T\delta\mathbf u_0
=\frac{\mathbf u_m^T\delta\mathbf A\,\mathbf n}{\lambda_0-\lambda_m}.
\]

又因为 \(\|\mathbf u_0+\delta\mathbf u_0\|=1\)，一阶意义下 \(\mathbf u_0^T\delta\mathbf u_0=0\)，所以

\[
\boxed{
\delta\mathbf n
=\sum_{m=1,2}
\frac{\mathbf u_m^T\delta\mathbf A\,\mathbf n}{\lambda_0-\lambda_m}\,\mathbf u_m
}
\tag{4.3}
\]

#### 4.3.3 代入 \(\delta\mathbf A\)

\[
\mathbf u_m^T\delta\mathbf A\,\mathbf n
=\frac1N\left[
(\mathbf u_m^T\delta\mathbf p_i)(\mathbf v_i^T\mathbf n)
+(\mathbf v_i^T\mathbf u_m)(\mathbf n^T\delta\mathbf p_i)
\right].
\]

代回 (4.3)：

\[
\boxed{
\frac{\partial\mathbf n}{\partial\mathbf p_i}
=\sum_{m=1,2}
\frac{1}{N(\lambda_0-\lambda_m)}
\left[
(\mathbf v_i^T\mathbf n)\,\mathbf u_m\mathbf u_m^T
+(\mathbf v_i^T\mathbf u_m)\,\mathbf u_m\mathbf n^T
\right]
}
\tag{4.4}
\]

若点严格落在平面上，\(\mathbf v_i^T\mathbf n\approx0\)，第一项（对称项）可以忽略，退化成常见的

\[
\frac{\partial\mathbf n}{\partial\mathbf p_i}
\approx
\sum_{m=1,2}
\frac{\mathbf v_i^T\mathbf u_m}{N(\lambda_0-\lambda_m)}
\,\mathbf u_m\mathbf n^T.
\tag{4.5}
\]

#### 4.3.4 代码里的 \(F_m\) 与 \(\mathbf U\mathbf F\)

代码构造的是式 (4.4) 的“行形式”。令

\[
\mathbf F_m
=\frac{1}{N(\lambda_0-\lambda_m)}
\mathbf v_i^T
\left(\mathbf u_m\mathbf n^T+\mathbf n\mathbf u_m^T\right)
=\frac{1}{N(\lambda_0-\lambda_m)}
\left[
(\mathbf v_i^T\mathbf u_m)\mathbf n^T
+(\mathbf v_i^T\mathbf n)\mathbf u_m^T
\right].
\]

这是一个 \(1\times3\) 行向量。代码：

```cpp
F_m = (pv.point - mean).transpose() / (N * (evals(0)-evals(m)))
    * (u_m * n^T + n * u_m^T);
F.row(m) = F_m;
```

然后把 \(\mathbf F\) 的每一行按 \(m=1,2\) 填好（第 0 行保持零），再算

\[
\mathbf U\mathbf F
=\sum_{m=1,2}\mathbf u_m\mathbf F_m
=\frac{1}{N(\lambda_0-\lambda_m)}
\left[
(\mathbf v_i^T\mathbf u_m)\mathbf u_m\mathbf n^T
+(\mathbf v_i^T\mathbf n)\mathbf u_m\mathbf u_m^T
\right],
\]

正好等于式 (4.4)。所以 `J.block<3,3>(0,0) = evecs * F;` 就是 \(\partial\mathbf n/\partial\mathbf p_i\)。

### 4.4 质心对点的雅可比

质心是均值：

\[
\mathbf q=\frac1N\sum_{j=1}^N\mathbf p_j
\quad\Longrightarrow\quad
\frac{\partial\mathbf q}{\partial\mathbf p_i}=\frac1N\mathbf I_3.
\tag{4.6}
\]

代码：

```cpp
Eigen::Matrix3d J_Q = Eigen::Matrix3d::Identity() / N;
J.block<3,3>(3,0) = J_Q;
```

### 4.5 拼成 \(6\times6\) 平面协方差

把法向和质心的雅可比拼起来：

\[
\mathbf J_i=
\begin{bmatrix}
\partial\mathbf n/\partial\mathbf p_i\\
\partial\mathbf q/\partial\mathbf p_i
\end{bmatrix}
=
\begin{bmatrix}
\mathbf U\mathbf F\\
\mathbf I/N
\end{bmatrix}
\in\mathbb R^{6\times3}.
\tag{4.7}
\]

假设不同点的噪声相互独立（近似），则

\[
\boxed{
\boldsymbol\Sigma_{nq}
=\sum_{i=1}^N
\mathbf J_i\,\boldsymbol\Sigma_i\,\mathbf J_i^T
}
\tag{4.8}
\]

展开成四个块：

\[
\boxed{
\begin{aligned}
\boldsymbol\Sigma_{nn}
&=\sum_i(\mathbf U\mathbf F)\boldsymbol\Sigma_i(\mathbf U\mathbf F)^T,\\
\boldsymbol\Sigma_{nq}
&=\sum_i(\mathbf U\mathbf F)\boldsymbol\Sigma_i\left(\frac1N\mathbf I\right),\\
\boldsymbol\Sigma_{qn}
&=\boldsymbol\Sigma_{nq}^T,\\
\boldsymbol\Sigma_{qq}
&=\frac1{N^2}\sum_i\boldsymbol\Sigma_i.
\end{aligned}
}
\tag{4.9}
\]

代码：

```cpp
plane_->cov += J * pv.cov * J.transpose();
```

就是在累加式 (4.8)，**完整保留法向-质心的交叉块**。

几个性质：

- \(\boldsymbol\Sigma_{nn}\) 的秩至多 2：因为 \(\delta\mathbf n\perp\mathbf n\)，法向只有 2 个有效方向。
- \(\boldsymbol\Sigma_{qq}\) 按 \(1/N^2\) 下降：点越多，质心越确定。
- \(\boldsymbol\Sigma_{nq}\ne\mathbf 0\)：法向和质心都由同一批点估计，噪声会把平面“掰弯”的同时移动质心。
- 整个 \(6\times6\) 协方差有一个零空间方向 \([\mathbf n;\mathbf 0]\)（法向缩放），所以秩至多 5。点到面残差恰好不受这个方向影响。

### 4.6 代码实现检查清单

1. **`Plane::cov` 没有显式初始化**。`voxel_map.h` 里：
   ```cpp
   Eigen::Matrix<double, 6, 6> cov;
   ```
   Eigen 的固定尺寸矩阵默认构造不保证清零；即使 `make_shared<Plane>()` 的值初始化在某些编译器上恰好清零，也不应依赖。`+=` 前应显式清零。建议写成
   ```cpp
   Eigen::Matrix<double, 6, 6> cov = Eigen::Matrix<double, 6, 6>::Zero();
   ```
2. **`updatePlane()` 累加前没有清零**。`updatePlane()` 会被多次调用（每 `update_point_thresh_` 个点一次），而 `plane_->cov += ...` 没有先 `setZero()`，会把同一批点重复累加。应在循环前：
   ```cpp
   plane_->cov.setZero();
   ```
   然后对 `temp_points_` 全量累加一次。
3. **`buildResidual()` 没有把平面协方差写入 `ResidualData`**。代码注释说“回填平面参数”，但只写了 `plane_norm` 和 `plane_mean`，没有
   ```cpp
   data.plane_cov = voxel_grid->plane_->cov;
   ```
   否则后面的 `sigma_l` 和 IESKF 权重用的是 `ResidualData::plane_cov` 的未初始化值。
4. **`ResidualData::plane_cov` 也没有默认初始化**，建议在结构体里写成 `Eigen::Matrix<double,6,6> plane_cov = Eigen::Matrix<double,6,6>::Zero();`。
5. **`is_valid` 的过期问题**：`sharedUpdateFunc()` 在未命中体素时不会调用 `buildResidual()`，`is_valid` 会保留上一次的值。应在每次迭代/每帧开始时置 `false`，或未命中时显式 `data.is_valid = false;`。
6. **法向符号**：`updatePlane()` 在协方差计算之后才统一法向朝向。这没问题，因为协方差只用 \(\mathbf J\mathbf J^T\)，对 \(\mathbf n\to-\mathbf n\) 不敏感；但后续残差和合并必须使用统一后的 `plane_->norm`。
7. **独立性/一阶假设**：式 (4.8) 假设不同点的噪声独立；实际地图点共享建图位姿误差，存在共同模态。论文也做了同样的近似，结果会偏乐观。
8. **`merge()` 的加权平均括号**：`new_mean` / `new_norm` 的括号位置不对（代码注释里也标了）。当前写法等价于
   \[
   \text{new\_mean}=t_{m0}\mathbf q_1+\frac{t_{m1}\mathbf q_2}{t_{m0}+t_{m1}},
   \]
   而预期是
   \[
   \text{new\_mean}=\frac{t_{m0}\mathbf q_1+t_{m1}\mathbf q_2}{t_{m0}+t_{m1}}.
   \]
   这会直接影响合并后的平面参数，进而影响后续残差和 3σ 门限。

## 5. 点到面残差与 3σ 检验：`buildResidual()`

### 5.1 残差

平面用 \((\mathbf n,\mathbf q)\) 表示：

\[
\mathbf n^T(\mathbf x-\mathbf q)=0.
\]

世界系点 \(\mathbf p_w\) 到平面的有符号距离：

\[
\boxed{
r=\mathbf n^T(\mathbf p_w-\mathbf q)
}
\tag{5.1}
\]

- \(r=0\)：点在平面上；
- \(r>0\) / \(r<0\)：点在法向正侧/负侧。

代码：

```cpp
Eigen::Vector3d p2m = data.point_world - voxel_grid->plane_->mean;
data.residual = data.plane_norm.dot(p2m);
```

### 5.2 残差对平面参数的雅可比

\(r\) 同时依赖 \(\mathbf n\)、\(\mathbf q\) 和 \(\mathbf p_w\)：

\[
\frac{\partial r}{\partial\mathbf n}=(\mathbf p_w-\mathbf q)^T,\qquad
\frac{\partial r}{\partial\mathbf q}=-\mathbf n^T.
\]

所以

\[
\boxed{
\mathbf J_{nq}
=\big[(\mathbf p_w-\mathbf q)^T,\;-\mathbf n^T\big]
\in\mathbb R^{1\times6}
}
\tag{5.2}
\]

代码：

```cpp
J_nq.block<1,3>(0,0) = p2m;          // ∂r/∂n
J_nq.block<1,3>(0,3) = -plane_norm;  // ∂r/∂q
```

### 5.3 残差方差

平面参数本身有协方差 \(\boldsymbol\Sigma_{nq}\)，当前点有协方差 \(\boldsymbol\Sigma_w\)。一阶传播：

\[
\boxed{
\sigma_r^2
=\mathbf J_{nq}\boldsymbol\Sigma_{nq}\mathbf J_{nq}^T
+\mathbf n^T\boldsymbol\Sigma_w\mathbf n
}
\tag{5.3}
\]

第一项是地图平面不确定度的贡献；第二项是当前点不确定度在法向上的投影（因为 \(\partial r/\partial\mathbf p_w=\mathbf n^T\)）。

代码：

```cpp
double sigma_l = J_nq * data.plane_cov * J_nq.transpose();
sigma_l += data.plane_norm.transpose() * data.cov_world * data.plane_norm;
```

> 注意：`sigma_l` 是**方差**，不是标准差；下面要 `sqrt`。

### 5.4 3σ 检验

在零假设“点确实落在该平面上”下：

\[
r\sim\mathcal N(0,\sigma_r^2)
\quad\Longrightarrow\quad
\frac{r}{\sigma_r}\sim\mathcal N(0,1).
\]

因此

\[
\boxed{
|r|<3\sigma_r
}
\tag{5.4}
\]

约 99.7% 置信。超过就认为该点到面匹配不可信，标记为外点：

- 体素量化导致点落到错误平面；
- 动态物体；
- 非平面结构（树叶、草丛）；
- 地图或位姿误差过大。

代码：

```cpp
if (std::abs(data.residual) < 3.0 * std::sqrt(sigma_l))
    data.is_valid = true;
```

### 5.5 为什么用自适应门限

\(\sigma_r\) 会随场景自动变化：

- **远处点**：方向噪声 \(\times\) 距离、位姿杠杆臂变大 \(\Rightarrow \sigma_r\) 大 \(\Rightarrow\) 门限自动放宽；
- **近处点**：\(\sigma_r\) 小 \(\Rightarrow\) 门限收紧；
- **点多的平面 / 合并后的大平面**：`plane_cov` 小 \(\Rightarrow\) 门限收紧；
- **杂乱区域的“平面”**：`plane_cov` 大 \(\Rightarrow\) 门限放宽。

固定一个 0.1 m 之类的阈值，无法同时适应近/远、好/坏平面。

### 5.6 实现提醒

- `data.plane_cov` 必须在 `buildResidual()` 里从 `voxel_grid->plane_->cov` 拷贝过来，否则式 (5.3) 的第一项用的是未初始化值。
- `data.is_valid` 要在未命中体素时显式置 `false`，避免沿用上一帧的结果。
- 若 `plane_cov` 因上文第 4.6 节的初始化/清零问题而不准，3σ 门限也会跟着失准。

## 6. IESKF 观测权重与状态更新

### 6.1 为什么 3σ 用 `cov_world`，权重却用 `cov_lidar`

`buildResidual()` 的 3σ 门限问的是：

> “当前这个世界系点与地图平面是否统计一致？”

当前点的世界坐标 = 位姿 × 雷达点。位姿本身有误差，所以点的世界坐标不确定度里**必须**包含当前位姿不确定度 \(\mathbf P\)。因此用 `cov_world` 是对的。

但 IESKF 权重问的是：

> “这个观测应以多大权重进入滤波器？”

滤波器的状态就是位姿，位姿不确定度已经通过**先验项 \(\mathbf P^{-1}\)** 和状态雅可比 \(\mathbf H\) 进入正规方程。如果再在观测噪声 \(\mathbf R\) 里放一份含 \(\mathbf P\) 的 `cov_world`，同一份位姿不确定度就被算了两次，滤波器会**过度不信任**观测。

所以权重里只用：

\[
\boxed{
r\_cov
=\mathbf J_{nq}\boldsymbol\Sigma_{nq}\mathbf J_{nq}^T
+\mathbf n^T
\left(\mathbf R_{wl}\boldsymbol\Sigma_{\text{lidar}}\mathbf R_{wl}^T\right)
\mathbf n
}
\tag{6.1}
\]

即 **地图平面不确定度 + 雷达局部量测噪声**，不含当前位姿不确定度。

这正对应 VoxelMap 论文里：

- **式 (11)**：关联检验，用世界系点协方差 \(\boldsymbol\Sigma_{{}^{\mathrm W}\mathbf p}\)（含位姿误差）；
- **式 (13)**：状态估计观测噪声，用本体系点协方差 \(\boldsymbol\Sigma_{{}^{\mathrm L}\mathbf p}\)（不含位姿误差，避免重复计数）。

### 6.2 代码对应

`lio_builder.cpp` 的 `sharedUpdateFunc()`：

```cpp
double r_cov = Jn * data.plane_cov * Jn.transpose();          // 平面参数不确定度
r_cov += plane_norm.transpose()
       * r_wl * data.cov_lidar * r_wl.transpose()
       * plane_norm;                                           // 局部量测噪声在法向的投影
double r_info = r_cov < 0.0002 ? 5000 : 1.0 / r_cov;           // 信息权重，带下限保护
```

这里 `r_cov` 是标量方差，`r_info = 1/r_cov` 是信息权重。若方差太小（\(<2\times10^{-4}\)），信息权重封顶 5000，避免数值爆炸。

### 6.3 观测雅可比

残差对状态（位置、姿态、外参）的雅可比在 `sharedUpdateFunc()` 里组装：

```cpp
J.block<1,3>(0, 0) = plane_norm.transpose();                   // 位置
J.block<1,3>(0, 3) = -plane_norm.transpose() * state.rot
                   * Sophus::SO3d::hat(state.rot_ext * point_lidar + state.pos_ext); // 姿态
if (config_.estimate_ext)
{
    J.block<1,3>(0, 6) = -plane_norm.transpose() * r_wl
                       * Sophus::SO3d::hat(point_lidar);        // 外参旋转
    J.block<1,3>(0, 9) = plane_norm.transpose() * state.rot;    // 外参平移
}
```

状态里的旋转是 IMU 到世界的 \(\mathbf R_{wi}\)，外参是 \(\mathbf R_{IL},\mathbf t_{IL}\)。点的世界坐标写成：

\[
\mathbf p_w
=\mathbf R_{wi}\left(\mathbf R_{IL}\,^{\mathrm L}\mathbf p+\mathbf t_{IL}\right)
+\mathbf t_{wi}.
\]

对 \(\mathbf R_{wi}\) 做右扰动 \(\mathbf R_{wi}=\bar{\mathbf R}_{wi}\exp(\delta\boldsymbol\theta^\wedge)\)，对 \(\mathbf t_{wi}\) 做加性扰动：

\[
\delta\mathbf p_w
=-\bar{\mathbf R}_{wi}
\lfloor \mathbf R_{IL}\,^{\mathrm L}\mathbf p+\mathbf t_{IL}\rfloor_\times
\delta\boldsymbol\theta
+\delta\mathbf t_{wi}.
\]

于是

\[
\frac{\partial r}{\partial\delta\mathbf t_{wi}}=\mathbf n^T,\qquad
\frac{\partial r}{\partial\delta\boldsymbol\theta}
=-\mathbf n^T\bar{\mathbf R}_{wi}
\lfloor \mathbf R_{IL}\,^{\mathrm L}\mathbf p+\mathbf t_{IL}\rfloor_\times.
\]

外参旋转 \(\mathbf R_{IL}=\bar{\mathbf R}_{IL}\exp(\delta\boldsymbol\theta_{IL}^\wedge)\)：

\[
\delta\mathbf p_w
=-\mathbf R_{wi}\bar{\mathbf R}_{IL}\lfloor^{\mathrm L}\mathbf p\rfloor_\times
\delta\boldsymbol\theta_{IL}
=-\mathbf R_{wl}\lfloor^{\mathrm L}\mathbf p\rfloor_\times
\delta\boldsymbol\theta_{IL},
\]

\[
\frac{\partial r}{\partial\delta\boldsymbol\theta_{IL}}
=-\mathbf n^T\mathbf R_{wl}\lfloor^{\mathrm L}\mathbf p\rfloor_\times.
\]

外参平移：

\[
\frac{\partial r}{\partial\delta\mathbf t_{IL}}=\mathbf n^T\mathbf R_{wi}.
\]

对应代码里的两个外参块。注意 `cov_world` 里的杠杆臂用的是 `hat(point_lidar)`，严格应为 `hat(R_IL * p_l + t_IL)`；两者在外参接近单位阵时差异很小。

### 6.4 信息矩阵累加与 IESKF 更新

每个有效点累加：

\[
\mathbf H_{\text{obs}}
=\sum_i \mathbf J_i^T r\_info_i \mathbf J_i,
\qquad
\mathbf b_{\text{obs}}
=\sum_i \mathbf J_i^T r\_info_i r_i.
\tag{6.2}
\]

代码：

```cpp
shared_state.H += J.transpose() * r_info * J;
shared_state.b += J.transpose() * r_info * residual;
```

IESKF 把观测信息与先验信息相加。这里的 \(\mathbf J_{\text{prior}}\) 是 `ieskf.cpp` 里把“当前迭代点的误差参数化”换算到“先验参数化”的 \(23\times23\) 雅可比，**不是**前面那个 \(1\times12\) 的观测雅可比：

\[
\mathbf H
=\mathbf J_{\text{prior}}^T\mathbf P^{-1}\mathbf J_{\text{prior}}+\mathbf H_{\text{obs}},
\qquad
\mathbf b
=\mathbf J_{\text{prior}}^T\mathbf P^{-1}\boldsymbol\delta+\mathbf b_{\text{obs}},
\tag{6.3}
\]

\[
\boxed{
\boldsymbol\delta
=-\mathbf H^{-1}\mathbf b
}
\tag{6.4}
\]

迭代直到 \(\boldsymbol\delta\) 足够小，最后

\[
\mathbf P\leftarrow \mathbf L\mathbf H^{-1}\mathbf L^T.
\]

代码见 `ieskf.cpp` 的 `update()`。

> **近似提醒**：地图平面协方差 \(\boldsymbol\Sigma_{nq}\) 本身是在建图时用当时的位姿不确定度传播出来的，它和当前帧位姿是相关的。式 (6.1) 把地图不确定度和当前量测当成独立来源，忽略了这种相关性；论文也做了同样假设。若要更严格，需要把地图和当前状态联合建模（因子图/BA）。

## 9. 总结

这条链可以压缩成三句话：

1. **点协方差**：测距/测角噪声给出 \(\boldsymbol\Sigma_{\text{lidar}}\)，再叠加当前位姿误差得到 \(\boldsymbol\Sigma_w\)。
2. **平面协方差**：把 \((\mathbf n,\mathbf q)\) 看成点的函数，用特征向量扰动求 \(\partial\mathbf n/\partial\mathbf p\)、用均值求 \(\partial\mathbf q/\partial\mathbf p\)，再按 \(\sum\mathbf J\boldsymbol\Sigma\mathbf J^T\) 传播。
3. **残差与滤波**：残差 \(r=\mathbf n^T(\mathbf p-\mathbf q)\) 的方差由“平面不确定度 + 点不确定度”组成；3σ 用它做关联门限，IESKF 用“平面不确定度 + 局部量测噪声”做信息权重，避免与先验重复计数。

## 附录 A：\(\delta\mathbf A=\frac1N(\delta\mathbf p_i\mathbf v_i^T+\mathbf v_i\delta\mathbf p_i^T)\) 的推导

设

\[
\mathbf q=\frac1N\sum_j\mathbf p_j,\qquad
\mathbf v_j=\mathbf p_j-\mathbf q,\qquad
\sum_j\mathbf v_j=\mathbf 0.
\]

只扰动 \(\mathbf p_i\)，则

\[
\delta\mathbf q=\frac1N\delta\mathbf p_i,
\qquad
\delta\mathbf v_i=\delta\mathbf p_i-\delta\mathbf q
=\frac{N-1}{N}\delta\mathbf p_i,
\qquad
\delta\mathbf v_j=-\delta\mathbf q=-\frac1N\delta\mathbf p_i\quad(j\ne i).
\]

又

\[
\mathbf A=\frac1N\sum_j(\mathbf p_j-\mathbf q)(\mathbf p_j-\mathbf q)^T
=\frac1N\sum_j\mathbf v_j\mathbf v_j^T.
\]

所以

\[
\begin{aligned}
\delta\mathbf A
&=\frac1N\sum_j\left(\delta\mathbf v_j\mathbf v_j^T+\mathbf v_j\delta\mathbf v_j^T\right)\\
&=\frac1N\Big[
\frac{N-1}{N}\left(\delta\mathbf p_i\mathbf v_i^T+\mathbf v_i\delta\mathbf p_i^T\right)
-\frac1N\sum_{j\ne i}\left(\delta\mathbf p_i\mathbf v_j^T+\mathbf v_j\delta\mathbf p_i^T\right)
\Big].
\end{aligned}
\]

利用 \(\sum_{j\ne i}\mathbf v_j=-\mathbf v_i\)，第二项为

\[
-\frac1N\left(\delta\mathbf p_i(-\mathbf v_i)^T+(-\mathbf v_i)\delta\mathbf p_i^T\right)
=\frac1N\left(\delta\mathbf p_i\mathbf v_i^T+\mathbf v_i\delta\mathbf p_i^T\right).
\]

两项合并：

\[
\delta\mathbf A
=\frac1N\left[\frac{N-1}{N}+\frac1N\right]
\left(\delta\mathbf p_i\mathbf v_i^T+\mathbf v_i\delta\mathbf p_i^T\right)
=\frac1N\left(\delta\mathbf p_i\mathbf v_i^T+\mathbf v_i\delta\mathbf p_i^T\right).
\]

证毕。

## 附录 B：特征向量扰动公式

对对称矩阵 \(\mathbf A=\mathbf U\boldsymbol\Lambda\mathbf U^T\)，特征值互异。扰动后

\[
(\mathbf A+\delta\mathbf A)(\mathbf u_0+\delta\mathbf u_0)
=(\lambda_0+\delta\lambda_0)(\mathbf u_0+\delta\mathbf u_0).
\]

一阶项：

\[
\mathbf A\delta\mathbf u_0+\delta\mathbf A\mathbf u_0
=\lambda_0\delta\mathbf u_0+\delta\lambda_0\mathbf u_0.
\]

左乘 \(\mathbf u_m^T\)（\(m\ne0\)）：

\[
(\lambda_m-\lambda_0)\mathbf u_m^T\delta\mathbf u_0
+\mathbf u_m^T\delta\mathbf A\mathbf u_0=0,
\]

所以

\[
\mathbf u_m^T\delta\mathbf u_0
=\frac{\mathbf u_m^T\delta\mathbf A\mathbf u_0}{\lambda_0-\lambda_m}.
\]

由于 \(\mathbf u_0^T\delta\mathbf u_0=0\)（单位向量约束），

\[
\delta\mathbf n=\delta\mathbf u_0
=\sum_{m=1,2}
\frac{\mathbf u_m^T\delta\mathbf A\mathbf n}{\lambda_0-\lambda_m}\mathbf u_m.
\]

## 附录 C：为什么 \(\mathbf U\mathbf F\) 等于法向雅可比

代码里

\[
\mathbf F_m
=\frac{1}{N(\lambda_0-\lambda_m)}
\mathbf v_i^T
\left(\mathbf u_m\mathbf n^T+\mathbf n\mathbf u_m^T\right).
\]

展开：

\[
\mathbf F_m
=\frac{1}{N(\lambda_0-\lambda_m)}
\left[
(\mathbf v_i^T\mathbf u_m)\mathbf n^T
+(\mathbf v_i^T\mathbf n)\mathbf u_m^T
\right].
\]

于是

\[
\mathbf U\mathbf F
=\sum_{m=1,2}\mathbf u_m\mathbf F_m
=\sum_{m=1,2}
\frac{1}{N(\lambda_0-\lambda_m)}
\left[
(\mathbf v_i^T\mathbf u_m)\mathbf u_m\mathbf n^T
+(\mathbf v_i^T\mathbf n)\mathbf u_m\mathbf u_m^T
\right],
\]

正好是式 (4.4) 的两项。注意 \(\mathbf F\) 的第 0 行保持为零，因为循环从 \(m=1\) 开始；这对应“法向自身方向不参与”的约束。

## 附录 D：IESKF 正规方程的来源

MAP 目标：

\[
J(\mathbf x)
=\|\mathbf x\boxminus\hat{\mathbf x}\|_{\mathbf P}^2
+\sum_i\|h_i(\mathbf x)\|_{\mathbf R_i}^2.
\]

在当前迭代点 \(\bar{\mathbf x}\) 线性化：

\[
h_i(\mathbf x)\approx h_i(\bar{\mathbf x})+\mathbf H_i\boldsymbol\delta\mathbf x,
\qquad
\boldsymbol\delta\mathbf x=\mathbf x\boxminus\bar{\mathbf x}.
\]

令 \(\mathbf r_i=h_i(\bar{\mathbf x})\)，对 \(\boldsymbol\delta\mathbf x\) 求导置零：

\[
\left(\mathbf P^{-1}+\sum_i\mathbf H_i^T\mathbf R_i^{-1}\mathbf H_i\right)\boldsymbol\delta\mathbf x
=\mathbf P^{-1}(\hat{\mathbf x}\boxminus\bar{\mathbf x})
-\sum_i\mathbf H_i^T\mathbf R_i^{-1}\mathbf r_i.
\]

第一次迭代 \(\bar{\mathbf x}=\hat{\mathbf x}\) 时，右边第一项为零，得到

\[
\boldsymbol\delta\mathbf x
=-\left(\mathbf P^{-1}+\mathbf H_{\text{obs}}\right)^{-1}\mathbf b_{\text{obs}},
\]

其中

\[
\mathbf H_{\text{obs}}=\sum_i\mathbf H_i^T\mathbf R_i^{-1}\mathbf H_i,
\qquad
\mathbf b_{\text{obs}}=\sum_i\mathbf H_i^T\mathbf R_i^{-1}\mathbf r_i.
\]

迭代地令 \(\bar{\mathbf x}\leftarrow\bar{\mathbf x}\boxplus\boldsymbol\delta\mathbf x\)，就是 IESKF。

> 注：严格的 IESKF 还要处理“当前迭代点误差参数化”到“先验参数化”的换算，即代码里的 `Matrix23d J`（本文记作 \(\mathbf J_{\text{prior}}\)），所以实际正规方程是 6.4 节的式 (6.3)。上面的推导省略了这一步，只展示 MAP → 正规方程的结构。
